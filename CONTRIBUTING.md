# Working on this repository

This is a personal engineering study lab. Contributions are welcome when they improve technical accuracy, reproducibility, or clarity.

## Adding a topic

1. Create a folder under `topics/` using a meaningful category.
2. Start with the template in [`docs/study-template.md`](docs/study-template.md).
3. Link the topic from the root README.
4. Include commands and expected output for experiments.
5. Cite official documentation for behavior that may change.
6. Mark an experiment as **Verified** only after executing it.

## Quality checklist

- [ ] The problem and intended use case are clear.
- [ ] Prerequisites are listed.
- [ ] Commands are reproducible from a clean environment.
- [ ] Expected results and troubleshooting notes are included.
- [ ] Security considerations are covered where relevant.
- [ ] The status accurately reflects what was tested.
