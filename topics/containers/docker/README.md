# Docker and reproducible Java environments

**Status:** Planned

## Study goals
- Images, containers, volumes, networks, and Compose.
- Multi-stage builds and running Java apps as non-root.
- Configuration through environment variables and secret handling.
- Health checks, logs, and local dependencies for integration tests.

## Practice
Containerize a Spring Boot API and run it with PostgreSQL and Redis through Docker Compose. Document build, startup, health check, and cleanup commands.
