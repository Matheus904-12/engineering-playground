# HTTP, DNS, and TLS fundamentals

**Status:** Planned

## Study goals
- DNS lookup, TCP connection, TLS handshake, and HTTP request lifecycle.
- HTTP methods, status codes, headers, caching, and keep-alive.
- TLS certificates, trust chains, and certificate validation.
- How to debug requests from a Java client and a Spring Boot server.

## Practice
Call a local Java endpoint with curl, inspect headers and status codes, and document the request lifecycle. Use HTTPS in any deployed experiment.
