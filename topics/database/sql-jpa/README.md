# SQL, transactions, and persistence with Java

**Status:** Planned

## Study goals
- SELECT, INSERT, UPDATE, DELETE, joins, indexes, and query plans.
- Constraints, normalization, and relational modeling.
- ACID, transaction boundaries, isolation, and locking.
- JDBC fundamentals and how JPA/Hibernate differs from SQL.
- N+1 queries, pagination, migrations, and connection pools.

## Practice
Implement a Spring Data JPA repository backed by PostgreSQL, write migrations, inspect generated SQL, and test transaction behavior. Do not rely on ORM abstractions without understanding the SQL.

- [PostgreSQL documentation](https://www.postgresql.org/docs/)
- [Spring Data JPA](https://docs.spring.io/spring-data/jpa/reference/)
