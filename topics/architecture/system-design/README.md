# System design fundamentals

**Status:** Planned

## Study goals
- Functional and non-functional requirements, constraints, and SLOs.
- Capacity estimates, bottlenecks, caching, queues, and data stores.
- Monolith vs. modular monolith vs. microservices.
- Consistency, availability, partition tolerance, and failure domains.
- Trade-offs: every design should explain why it fits the requirements.

## Practice
Design a URL shortener or ticket-monitoring service. Write requirements, API contracts, a high-level diagram, data model, bottlenecks, and failure scenarios. Use Java/Spring Boot for any runnable service prototype.
