# JVM and Java performance fundamentals

**Status:** Planned

## Study goals
- Heap vs. stack, garbage collection, and allocation pressure.
- Profiling before optimizing; CPU, memory, and latency.
- Thread pools, blocking calls, and connection pool sizing.
- Throughput vs. latency and basic load testing.

## Practice
Benchmark a small Java endpoint, record a baseline, change one variable, and compare results. Avoid making performance claims without measurements.
