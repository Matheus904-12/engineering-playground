# CI/CD with GitHub Actions for Java

**Status:** Planned

## Study goals
- Build, test, package, and publish artifacts.
- Maven/Gradle dependency caching and Java version matrices.
- Branch protection, pull requests, secrets, and least privilege.
- Keep workflows reproducible and avoid exposing credentials in logs.

## Practice
Create a workflow that checks out the repository, configures Java, runs unit tests, and builds a Spring Boot artifact on every pull request.
