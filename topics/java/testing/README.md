# Testing Java applications

**Status:** Planned

## Study goals
- Unit vs. integration tests and the test pyramid.
- JUnit 5 assertions, lifecycle, parameterized tests, and test naming.
- Mockito for collaboration boundaries; avoid mocking everything.
- Spring Boot integration tests and Testcontainers when useful.
- Test edge cases, failure paths, and business rules.

## Practice
Test a service with success, validation, not-found, and dependency-failure cases. Add at least one integration test against a real database container when ready.
