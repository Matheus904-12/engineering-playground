# REST APIs with Spring Boot

**Status:** Planned

## Study goals
- Controllers, services, repositories, DTOs, and dependency injection.
- HTTP methods and status codes, validation, pagination, and error responses.
- Configuration by profiles and environment variables.
- API documentation with OpenAPI.
- Keep business logic out of controllers and avoid unnecessary layers.

## Practice
Create a Java Spring Boot CRUD API with request/response DTOs, Bean Validation, consistent error handling, and tests. Document curl examples and expected responses.
