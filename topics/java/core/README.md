# Java fundamentals

**Status:** Planned

## Study goals
- OOP, interfaces, composition, inheritance, and encapsulation.
- Collections, generics, records, enums, exceptions, and immutability.
- Streams and lambdas without sacrificing readability.
- `equals`/`hashCode`, `Optional`, and common pitfalls.
- JVM, memory basics, garbage collection, and thread safety at a conceptual level.

## Practice
Build small, tested Java examples for a domain model, validation, collection transformations, and exception handling. Use JUnit 5 tests and explain the choices.
